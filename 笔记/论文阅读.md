## 从分析力学到伺服约束
### 被动约束下系统的力学分析

在分析力学中，我们将系统受到的力分为**主动力(Given/impressed)**和**约束力(Constraints)**。

**受约束系统的运动是有结构的"the motion of system under constrains has structure"**

所谓"结构(Structure/Form)"是一种**几何**上的概念，譬如受平面约束的物体只能在平面的上面移动，单摆底端只能在对应摆长的圆弧上运动。有结构的运动实际上是指该运动可以通过几何和流形来描述。

需要强调的是，**物体的运动可以通过几何和流行描述**实际上暗含了**系统的运动速度方向由约束决定**这一条件。受约束的系统运动速度沿其运动流形的切向。

运动之所以具有"结构"，是因为能产生该运动的系统收到了**约束**。

在分析力学两大基本理论：
1. 虚位移和虚功原理
	1. 理想约束是虚功为零的约束
	2. 虚位移是假想的位移，发生在一个时刻上
	3. 虚功是力使系统发生虚位移所需要的能量
2. 约束松弛原理
	-  用力来描述约束
**拉格朗日形式的达朗贝尔原理**：
分析力学中将动力学问题转化为虚功平衡的基本原理，标准形式写作$\sum_{i=1}^{N}(F_i - m_i a_i)\delta r_i = 0$
描述的物理意义为：在任意满足约束的虚位移上，主动力与惯性力的虚功为零。
**约束松弛原理**：
如果解除系统的某个约束，同时把这个约束原来产生的约束力作为外力作用在系统上，那么系统原有的运动状态不发生改变。

我们以广义状态为$q$，受力为$Q$的机械系统为例

系统的总动能为
$$T = \frac{1}{2}\dot{q}^{T}M\dot{q} + N\dot{q} + P$$
其中，第一项$\frac{1}{2}\dot{q}^{T}M\dot{q}$包含了所有传统力学思维中的“动能”，包括平动动能和转动动能，若从几何流形的角度考虑，其中$M$矩阵是系统运动流形上沿速度方向的黎曼度量，描述了系统在流形上运动的惯性，这种惯性直接由流形的几何特征决定，正如质量作为我们时空的惯性表征，描述了我们沿受质量扭曲的时空中某一流形运动时所具有的惯性，这种惯性和受质量扭曲的时空的几何特征决定，运动其实是沿扭曲时空“上坡”的过程，这也是惯性“抵抗”状态改变（运动）的表现；第二项$N\dot{q}$则描述了系统中所有的速度方向变化，需要注意的是，这里与传统力学中我们理解的“动能”不同，这一项描述了系统运动时速度方向的变化，是“不做功的几何动量”，它不提供真实机械能，但是能完整的表述流形几何特征对运动方向的约束，譬如在一个二维平面上的螺旋形流形，当系统在流形上运动时，如果从流形内部观测，系统始终向前运动，方向没有改变，但是从二维平面上观测，系统的运动方向始终随着处于流形不同位置而发生改变，这种速度方向的改变是流形的几何特征决定的，属于系统运动流形本身的惯性效应，而这种流形改变系统运动方向的几何特征，则可以通过“挠率”来度量；第三项$P$是坐标系或约束几何自身运动所贡献的动能项。

假设系统受到$m$个被动约束
$$\sum_i A_{li}\dot{q}_i + A_l = 0, \quad l = 1, ..., m$$
而满足这个方程的速度$\dot{q}$被称为**可能速度**，即可能速度在任意时刻都满足由上式所定义的线性微分方程；本质上就是在被动约束作用下的系统在其运动流形中的速度。
其中第一项为$\sum_i A_{li}\dot{q}_i$，系统运动流形余切空间上的一个向量，描述了系统速度在约束流形法向上的投影，表现了约束时变时系统试图“穿过”约束面的速度，而第二项$A_l$则描述了这个速度的大小，由于$A_{li}$和$A_l$都是时间的函数，因此该公式表示了当被动约束流形随时间变化时，被动约束将系统的状态限制在变化的约束流形上，例如在平面上运动的小球受平面的约束（不考虑摩擦），则小球会随着平面上升而上升。
将上式写成微分形式
$$\sum_i A_{li}dq_i + A_ldt = 0, \quad l = 1, ..., m$$
其中第一项从原来的广义速度向量变为位置微分向量——位移

令$Q^c_i, \quad i = 1, ..., n$表示沿$q_i$方向的约束力，对系统进行受力分析，由于系统具有动能$T$则系统所受合外力可以由动能直接表示
$$\frac{d}{dt} \frac{\partial T}{\partial \dot{q}_i} - \frac{\partial T}{\partial q_i}$$
其中第一项$\frac{d}{dt} \frac{\partial T}{\partial \dot{q}_i}$通过动能对速度求偏导后在对时间求导得到，第二项$\frac{\partial T}{\partial q_i}$由动能对广义坐标求偏导得到，反应质量矩阵、坐标映射等对位置的依赖。

在拉格朗日力学理论中，力被分为主动力和约束力，前文提到系统的主动力为$Q$，约束力为$Q^c$，在第$i$个广义坐标分量方向：
$$\frac{d}{dt} \frac{\partial T}{\partial \dot{q}_i} - \frac{\partial T}{\partial q_i} = Q_i + Q^c_i$$


在被动约束下的虚位移$\delta q = [\delta q_1, \delta q_2, ..., \delta q_n]^T$满足：
$$\sum_{i = 1}^n A_{li}(q,t) \delta q = 0, \quad l = 1, ..., m$$
对应的虚功为：
$$\delta 'W^c = Q^{cT} \delta q = \sum_{i=1}^{n} Q^c_i \delta q_i = 0$$
由**拉格朗日形式的达朗贝尔原理**：
$$\sum_{i=1}^{n}(\frac{d}{dt} \frac{\partial T}{\partial \dot{q}_i} - \frac{\partial T}{\partial q_i} - Q_i)\delta q_i = 0$$
在应用了**约束松弛原理**之后，系统的拉格朗日运动方程化为：
$$\frac{d}{dt} \frac{\partial T}{\partial \dot{q}_i} - \frac{\partial T}{\partial q_i} - Q_i - \sum_{l=1}^{m}\lambda_l A_{li} = 0$$
其中$\lambda_l$是拉格朗日乘子，约束力$Q^c_i$可以通过拉格朗日乘子表示$Q_i^c = \sum_{l = 1}^{m}\lambda_l A_{li}$。

这里要理解，被动约束是通过拉格朗日乘子转化成约束力的，换言之，约束力通过拉格朗日乘子定义，只有当约束确定之后，约束力的结构才被确定。之前我们提到过，含有可能速度的被动约束方程实际上描述了被动约束的方向和大小，这里就是通过拉格朗日乘子将每个状态分量方向上的约束力显式表述了。

目前我们已经引入了n个系统状态和m个约束条件，构成了$n+m$个方程的方程组，此时**被动约束问题**可以直接描述为：**对于给定的初始状态$q_0$和$\dot{q}_0$可以得到此后任意时刻的状态$q(t)$,$\dot{q}(t)$和约束$\lambda_i(t)$**。

### 伺服约束下系统的力学分析
对于过去拉格朗日动力学领域内的研究，学者们主要聚焦于**被动约束**。所谓被动约束是指系统固有的，自发提供的约束，如平面提供的支持力，绳提供的拉力等。

与之相反的，伺服约束表示主动施加的指定系统运动结构的约束。

本文要求机械系统始终遵从一系列设定的约束，这就需要我们通过控制器来提供适当的约束力，这种约束力是被动约束无法提供的。

1. 二阶伺服约束的提出
2. 求解满足任务所需的约束力，讨论主动约束力与被动约束力之间的关系
3. 构建能产生约束力的伺服控制器
