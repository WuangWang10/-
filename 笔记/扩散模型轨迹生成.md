# 使用扩散模型进行轨姿规划

本文从扩散模型的原理出发，再与固定翼无人机项目结合，讲述项目中固定翼无人机使用扩散模型进行轨姿规划的思路和实现。

---

## 一. 扩散模型的原理

“扩散”描述了从清楚的原始数据逐渐加噪变成了易于描述的噪声数据的过程。

这在扩散模型中被称为“前向过程”，在前向过程中，扩散模型不使用神经网络，而是通过人为设定的程序和噪声调度，使得训练数据中的每个样本在最终时刻都近似服从同一个简单的高斯分布。

扩散模型学习从易于描述的噪声数据中逐步去噪还原成清晰的原始数据的过程，最终实现从噪声中去噪得到我们期望的目标数据。

## 二. 前向过程

对于原始数据$x_0$。人为规定加噪过程：

$q(x_t|x_{t-1}) = \mathcal N(x_t;\sqrt{1-\beta_t}x_{t-1},\beta_tI)$

或写作：

$x_t = \sqrt{1-\beta_t}x_{t-1} + \sqrt{\beta_t}\epsilon_t$

其中：

$t = 1, ..., T$是扩散步数

$\beta_t$是第$t$步加入的噪声强度

$\epsilon_t \sim \mathcal{N}(0,I)$

每一步只加入一点噪声，经过足够多步加噪，到第$T$步之后数据$x_T$几乎是纯高斯噪声。

**这个加噪过程是纯人为定义、设计的，不需要神经网络参与，对于扩散模型的使用者来说是完全透明、可解释的。**

### 高斯噪声的优势

得益于高斯分布信息量低，数学表示简单而且经由线性变换后仍保持高斯分布的特性，扩散模型的加噪去噪采用高斯噪声来完成。

1. 信息量低

一个一维高斯分布只需要两个参数：均值$\mu$和方差$\sigma^2$

$x \sim \mathcal N(\mu, \sigma^2)$

在扩散模型中往往使用标准高斯分布：

$x \sim \mathcal N(0,I)$

即每个维度都满足均值为0，方差为1的高斯分布，并且彼此独立，便于处理信息量大的原始数据张量。

2. 数学表示简单

多维标准高斯分布的概率密度是：

$p(x) = \frac{1}{(2\pi)^{\frac{d}{2}}}e^{(-\frac{1}{2}\left\|x\right\|^2)}$

其只依赖于$x$到原点的距离，而且形状为标准的“钟形”

对应的对数概率为：

$\log{p(x)} = C - \frac{1}{2}\left\|x\right\|^2$

梯度为

$\nabla_x\log{p(x)} = -x$

3. 经过线性变换后仍然保持高斯分布

正是由于高斯分布的这条性质，我们定义：$\alpha_t = 1 - \beta_t$，$\bar{\alpha}_t = \prod_{x=1}^{t}\alpha_{t}$

此时，在已知原始数据后加噪$t$步的数据满足的概率分布为：

$q(x_t|x_0) = \mathcal N(x_t;\sqrt{\bar{\alpha}_t}x_0,(1-\bar{\alpha}_t)I)$

因此可以直接采样第$t$步加噪后的数据

$x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1 - \bar{\alpha}}\epsilon$

## 三. 反向过程

反向过程的目的是从加噪的低信息量噪声中，逐步去噪，得到高信息量的原始数据。

由于去噪过程难以获知计算，因此采用神经网络学习的方式来近似去噪运算。

$p_\theta(x_{t-1}|x_{t}) \approx q(x_{t-1}|x_{t})$

网络的输入为：

- 带噪数据

- 时间步

网络的输出为：

- 当前数据中包含的噪声

- 原始数据或者去噪方向

在经典的DDPM方法中，通过让神经网络预测加入的噪声$\epsilon_\theta(x_t,t)$，来使得均方误差定义的目标函数$\mathcal{L} = \mathbb{E}_{x_0,\epsilon,t}[\left\|\epsilon - \epsilon_\theta(x_t,t) \right\|^2]$收敛。训练得到的网络即可将带噪数据还原为与原始数据$x_0$具有相近数据分布的高信息量数据。

### 训练过程

1. 取真实数据$x_0$

2. 选择随机时间步$t$

3. 随机生成高斯噪声$\epsilon$

4. 构造带噪数据$x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon$

5. 初始化神经网络权值，希望网络能从$(x_t, t)$中预测$\epsilon$

6. 用均方误差训练网络更新权值直到满足收敛条件或最大步数

## 四. 轨姿规划中的扩散模型

在讨论使用扩散模型完成轨姿规划的问题时，我们首先要明确以下几个问题：

1. 规划扩散模型输入的数据是什么

2. 规划扩散模型输出的数据是什么

### 1. 条件扩散模型和条件向量

在扩散模型的输入中加入条件向量$c$，此时扩散模型称为**“条件扩散模型”**，可以通过条件向量指定扩散模型生成哪一类，什么规模的数据。

$$(z_n, n, c) \to \hat{\epsilon}$$

在本项目中，我们将条件向量指定为包含**“历史飞行信息$H$，目标关键帧$K$，关键帧掩码$m$，飞行任务约束$L$”**四种信息的向量$c = \mathcal f(H, K, m, L)$。

1. 历史状态条件$H$

若规划开始前取最近$M$个采样点，则：

$$H = [h_{-M+1}, \ldots, h_0] \in \mathbb{R}^{M \times 27}$$

每个时刻的历史向量可以定义为

$$h_k = [p_k, v_k, q_k, \omega_k, u_k, e_{p,k}, e_{v,k}, e_{R,k}, s_k]$$

其中，

| **项目**     | **维数** | **内容**                             |
|:----------:|:------:|:----------------------------------:|
| $p_k$      | 3      | NED位置$p_N, p_E, p_D$               |
| $v_k$      | 3      | NED速度$v_N, v_E, v_D$               |
| $q_k$      | 4      | 机体到NED四元数                          |
| $\omega_k$ | 3      | 机体系角速度$p,q,r$                      |
| $u_k$      | 4      | 控制量：推力，副翼，升降舵，方向舵                  |
| $e_{p,k}$  | 3      | NED位置误差$e_{p,N}, e_{p,E}, e_{p,D{$ |
| $e_{v,k}$  | 3      | NED速度误差$e_{v,N}, e_{v,E}, e_{v,D}$ |
| $e_{R,k}$  | 3      | 姿态误差旋转向量                           |
| $s_k$      | 1      | 当前动作相位                             |
| **合计**     | **27** | **每个历史时刻$h_k$为27维向量**              |

其中飞机状态对应13维$state_k = [p_k, v_k, q_k, \omega_k] \in \mathbb R^{13}$，姿态误差采用$e_R = \log{(R_{ref}^TR)} \in \mathbb R^3$，历史编码器采用GRU（门控循环单元, Gated Recurrent Unit）将历史特征$H$归一化后交给GRU建模序列关系得到$h_H = GRU(Norm(H))$。需要注意的是，历史窗口只包含规划时刻及之前的数据，不能包含动作执行之后的实际状态。

2. 目标关键帧$K$

将第$i$个关键帧定义为：$k_i = [\tau_i, \bar{p}_i, \bar{v}_i, q_i]$。其中$\tau_i = \frac{t_i}{T}\in\mathbb{R}$为归一化关键帧时刻；$\bar{p}_i\in\mathbb{R}^3$为相对规划起点的位置；$\bar{v}_i\in\mathbb{R}^3$为关键帧速度；$q_i\in\mathbb{R}^4$表示相对于初始姿态的四元数，因此$k_i \in \mathbb R^{11}$。

需要注意在进入神经网络前需要进行四元数符号连续化，以避免$q$与$-q$表示同一姿态造成跳变；另外一种可行的姿态表示是采用当前姿态相对于初始状态的旋转矩阵前两列组成的六维向量来表示当前姿态，这种姿态表示最终可以通过叉积运算还原成对应姿态的旋转矩阵。

由于我们的机动动作有关键帧定义，因此关键帧参数$K$也代表了任务类型。我们定义的Loop机动含13个关键帧，而Immelmann Turn则只有11个关键帧。因此在统一编码关键帧参数时采用$K\in\mathbb{R}^{13}$并使用关键帧掩码$m$填充维度。

$$m_i = \begin{cases} 1,& \quad \text{真实关键帧}\\ 0,& \quad\text{填充关键帧}\end{cases},\qquad m \in \{0,1\}^{13}$$

关键帧编码可以采用共享MLP加掩码池化$g_i = \operatorname{MLP}_{K}(k_i)$ ，$h_K = \frac{\sum_{i}m_i g_i}{\sum_i m_i}$。

3. 飞行任务约束$L$

定义18维飞机和任务约束向量：

$$L = [a,T,h_0,V_{min},V_{max},R_{min},n_{max},\omega_{max},v_w,m,S,b,\bar{c}]$$

其中

| **项目** | **维数** | **含义**                 |
| :--------: | :--------: | :------------------------: |
| $a$      | 2        | 动作类型(Loop/Immelmman) |
|$T$|1|动作总时长|
|$h_0$|1|初始高度|
|$V_{min},V_{max}$|2|允许速度范围|
|$R_{min}$|1|最小曲率半径|
|$n_{max}$|1|最大允许过载|
|$\omega_{max}$|3|最大角速度|
|$v_{w,N},v_{w,E},v_{w,D}$|3|NED风速|
|m|1|飞机质量|
|$S,b,\bar{c}$|3|机翼面积，翼展，平均气动弦长|
|合计|18||
